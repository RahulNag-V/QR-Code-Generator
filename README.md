# OmniQR Studio — Burgundy Elegance Edition

A sophisticated, minimal, and high-performance URL to QR Code generator styled in the **Burgundy Elegance** design system.

## 🎨 Design System: Burgundy Elegance

- **Primary Burgundy**: `#750923` (Main interactive actions, primary buttons, brand accents)
- **Primary Dark (Hover)**: `#5E061F` (Hover states for primary actions)
- **Dark Burgundy / Primary Text**: `#2B131F` (Headings, primary typography, high-contrast labels)
- **Secondary Burgundy**: `#EDC5C8` (Secondary buttons, active highlights)
- **Accent**: `#F7DFE0` (Active tab fills, selected badges, subtle tint overlays)
- **Muted**: `#F0E2E2` (Slider tracks, neutral badges, subtle container dividers)
- **Destructive / Error**: `#A92737` (Remove buttons, error warnings, invalid status pills)
- **Border**: `#EEDCDB` (Delicate burgundy-tinted borders across cards and inputs)
- **Card Surface**: `#FBF7F4` (Warm elevated card backgrounds)
- **Main Background**: `#FAF7F4` (Warm off-white light page canvas)
- **White**: `#FFFFFF` (Input fields, canvas stage holder, high-contrast button text)

---

- **Multi-Format Content & Media Generator**:
  - 🌐 **Website / URL**: Live normalized web link QR generator.
  - 🖼️ **Photo / Image**: Drag-and-drop or select any image (PNG, JPG, JPEG, WEBP, GIF, SVG, BMP, AVIF) or direct image URL with live thumbnail and metadata readout.
  - 🎬 **Video**: Upload video clips (MP4, WebM, MOV, OGV, M4V) or paste video links (YouTube, Vimeo, TikTok, MP4) with embedded video preview player.
  - 🎵 **Audio / Music**: Upload audio tracks (MP3, WAV, OGG, AAC, FLAC, M4A) or paste audio/music streaming links (Spotify, SoundCloud, podcasts) with HTML5 audio player.
  - 📄 **Document / File**: Upload PDF, Word (DOCX), Text (TXT), CSV, JSON, Excel (XLSX), or ZIP archives, or paste cloud document links.
  - 📶 **Wi-Fi Network**: Generate instant auto-connect Wi-Fi QR codes with SSID, password, security encryption (WPA/WPA2/WPA3, WEP, None), and hidden network toggle.
  - 👤 **Contact Card (vCard)**: Generate standard vCard 3.0 contact QR codes with name, phone, email, organization, title, and website.
  - 📝 **Plain Text**: Encode freeform messages, meeting notes, secret memos, or crypto addresses with real-time character and byte counter.
- **Real-Time Reactive Generation**: Live updating QR codes with instant preview and payload detection.
- **Rigid Box-Fitting Preview**: QR code maintains a strict 310px preview box with zero column blowout or layout shifting.
- **Dual Download Placement**: Fast-access download buttons directly below the live QR code box, as well as high-resolution export controls in the "Export & HD" customizer tab.
- **Burgundy Elegance Palettes**: Curated presets (*Burgundy Classic*, *Velvet Crimson*, *Rose Wine*, *Deep Plum*, *Warm Terracotta*, *Espresso Noir*, *Classic Onyx*, *Soft Blush*).
- **Custom Patterns & Shapes**:
  - Module styles: *Rounded*, *Dots*, *Square*, *Smooth*, *Classy*, *Classy Curve*.
  - Corner outer eyes: *Extra Rounded*, *Square*, *Circular Ring*.
  - Corner inner dots: *Circle Dot*, *Square Dot*.
  - Independent corner eye coloring.
- **Center Logo & Branding**:
  - Presets: *Link*, *Web*, *Google*, *GitHub*, *YouTube*, *X / Twitter*, *WhatsApp*.
  - Drag-and-drop custom logo upload (PNG, SVG, JPEG, WebP) with size and margin sliders.
  - 30% Error Correction Level (`H` level) ensures reliability even with logos.
- **Multiple High-Resolution Export Formats**:
  - **PNG** (standard web to 4K billboard 2000×2000px).
  - **SVG** (lossless infinite-resolution vector).
  - **JPEG** & **Print Layout**.
  - **1-Click Copy Image to Clipboard**.
- **Scan Simulation & History**:
  - Built-in link test button to verify destination URLs before distribution.
  - Persistent history in `localStorage` with 1-click reload and removal.

